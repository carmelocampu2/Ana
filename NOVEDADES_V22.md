# Versión 2.2 — Entrenamiento experto

- 15 preguntas originales adicionales de nivel experto, con explicaciones.
- Filtros de dificultad: normal, avanzada, experto y todas.
- Filtro de procedencia: originales y oficiales verificadas.
- **No se han añadido preguntas oficiales verificadas:** la categoría oficial permanece vacía hasta disponer del cuestionario oficial y una referencia comprobable de convocatoria.
- Mantiene la navegación, el guardado de exámenes, las estadísticas y la exportación de la versión 2.1.
- Caché de PWA actualizada a v22 para facilitar la actualización de instalaciones existentes.

## Instalación
Subir todos los archivos de este ZIP a la raíz del repositorio GitHub Pages, sustituyendo los existentes. Esperar el despliegue y abrir la web con conexión. Si la app instalada no cambia, revisar caché del sitio (el borrado de datos elimina progreso local).

## Nota
Las nuevas preguntas son de entrenamiento y no reproducen convocatorias oficiales. Comprobar legislación y protocolos vigentes antes de usar las respuestas como referencia profesional.
